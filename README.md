# Portfolio website

A simple portfolio starter for GitHub Pages using HTML, CSS, and JavaScript.

## Structure

```text
.
├── index.html            # Content and section TODOs
├── style.css             # Layout, colors, and styling TODOs
├── script.js             # Footer year and interaction TODOs
├── assets/
│   ├── README.md         # CV instructions
│   └── images/
│       └── README.md     # Photo and screenshot instructions
├── LICENSE
└── README.md
```

## TODO checklist

- [ ] Replace the name, title, introduction, and page description in `index.html`.
- [ ] Fill in About, Skills, Projects, Experience, and Education.
- [ ] Add contact links and project URLs using the commented examples.
- [ ] Add images under `assets/images/` and reference them in `index.html`.
- [ ] Add `assets/cv.pdf` and enable its download link.
- [ ] Customize colors and spacing in `style.css`.
- [ ] Add optional interactions in `script.js` if needed.
- [ ] Check the page on mobile and desktop and test all links.
- [ ] Publish through your repository's GitHub Pages settings when ready.

Search for `TODO` in the files to find the next editing steps.

## Local preview

Open `index.html` in a browser. No installation or build step is required.

Use relative asset paths such as `assets/images/profile.jpg` so they also work
when the website is hosted under a repository path.
